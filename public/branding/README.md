# Coptic icons

Derived from the ornate Coptic cross and central letter supplied by the project owner.

- `coptic-project.png`: gold-on-black project branding.
- `coptic-app.png`: opaque 1024×1024 navy-and-beige app export.
- `coptic-app-source.png`: original generated app artwork.

The app export is installed in the iOS AppIcon asset catalog. `app/icon.png` supplies the matching web icon. Keep the square artwork unrounded; iOS applies its own icon mask. Generated originals remain in the workspace's generated_images directory.
